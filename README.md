# Calculator Web Application

## Oasis Infobyte Internship – Level 2 Task

This project is a simple and responsive calculator developed as part of the Oasis Infobyte Web Development and Designing Internship. It performs basic arithmetic operations through an interactive and user-friendly interface. The main objective of this project was to strengthen my JavaScript fundamentals and improve my understanding of DOM manipulation.

## Features

- Perform addition, subtraction, multiplication, and division
- Supports decimal calculations
- Clear all (AC) functionality
- Responsive design for different screen sizes
- Simple and clean user interface

## Technologies Used

- HTML5
- CSS3
- JavaScript

## Project Structure

```
WebDev-L2-Calculator/
│── index.html
│── style.css
│── script.js
└── README.md
```

## How to Run

1. Clone or download the repository.
2. Open the Calculator project folder.
3. Open `index.html` in your browser.

## What I Learned

- JavaScript functions and events
- DOM manipulation
- Responsive web design
- Building interactive web applications

- **Internship:** Oasis Infobyte Web Development and Designing Internship
