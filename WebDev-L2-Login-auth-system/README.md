# Vaishnavi's Authentication System

A polished, beginner-friendly authentication system built with Node.js, Express, SQLite, and vanilla JavaScript.

## Features
- Responsive login and registration pages
- Modern glassmorphism-inspired UI
- Session-based authentication
- Password hashing with bcrypt
- Protected dashboard route
- Theme toggle and toast notifications

## Project Structure
- frontend/ — HTML, CSS, JS, and assets for the UI
- backend/ — server, routes, controllers, middleware, and SQLite database

## Run Locally
```bash
cd backend
npm install
npm start
```

Open http://localhost:3000

> Note: open the app through the running backend server, not the `file://` HTML files directly.
